**Правила ведения:**
- Запись = дата/время → источник (путь к пасту/файлу) → суть → что изменено/сделано → что открыто.
- Состояние проекта в §0 обновляется при каждой записи.
- Факты — только с проверкой (команда + вывод); без прогона — `NOT RUN`.
