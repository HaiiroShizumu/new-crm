## Сделано

1. `smb/deploy/docker-compose.yml`, блок `x-app-environment` (после `STORAGE_S3_*`,
   строка 33 была пустой — вставлены три строки):

```yaml
  SMB_BITRIX_CLIENT_ID: ${SMB_BITRIX_CLIENT_ID:-}
  SMB_BITRIX_CLIENT_SECRET: ${SMB_BITRIX_CLIENT_SECRET:-}
  SMB_BITRIX_AUTO_PROVISION_WORKSPACE: ${SMB_BITRIX_AUTO_PROVISION_WORKSPACE:-false}
```

2. `smb/deploy/.env.example`: те же три имени с пустыми значениями. Они уже были в файле, но
  закомментированы (`# SMB_BITRIX_CLIENT_ID=` и т. д.) — приведены к активным строкам, добавлена
  строка-пояснение «Empty means the channel is off: the server treats "" as unset».

Пустое значение безопасно: `parseSmbEnv` (`packages/twenty-server/src/modules/smb-config/utils/parse-smb-env.util.ts:8-18`)
специально превращает пустую строку в `undefined` («docker compose passes unset variables as empty
strings»), а `assertAllOrNone` для Bitrix24 требует либо оба ключа, либо ни одного
(`parse-smb-env.util.ts:82-85`). `${…:-false}` трактует пустую строку как незаданную → авто-создание
workspace выключено.
