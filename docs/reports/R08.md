## Расхождения

1. `bash scripts/check-core-patches.sh` (режим CI, `BASE...HEAD`) сейчас выдаёт `modules.module.ts` — **не из этой работы**: в `HEAD` закоммичен прежний шов P-002 в `modules.module.ts`, а возврат файла к upstream (ревизия R07, AR-1) лежит в индексе и не закоммичен. Файл равен `upstream-base`; предупреждение исчезнет с коммитом R07/R08.
2. Cron очистки ставится из `onModuleInit` (и сервера, и воркера), а не командой `cron:*` из общего списка ядра: строка в списке потребовала бы нового шва в ядре (ADR-009 п.4). Повторная постановка у BullMQ идемпотентна по имени и расписанию — **проверить на живой Redis** (NOT RUN).
3. Пункты TODO не закрыты `[x]`, кроме AR-5: правило «`[x]` только с выводом команды» выполнено для генератора (`node --test`), для остальных нужен jest в контейнере.
