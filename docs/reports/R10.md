## Расхождения / допущения

1. Хук `task.updateOne` и заглушка A2 висят на одном ключе — хранилище допускает несколько хуков на ключ (`workspace-query-hook.service.ts`: цикл по `preHookInstances`), но полагается на `merge`; проверить на стенде.
2. В SDK не проверен формат фильтров вью — вью «Мои задания / Поставленные мной / Просроченные» (T-7) не созданы.
3. Идентификаторы сущностей сгенерированы случайно и закреплены в `src/universal-identifiers.ts`; после первой установки не менять.
4. A-4 (создание отсутствий только ролью «Кадры») не реализовано: нужно понимать роль пользователя в хуке — вместе с P-4.
5. F-5 (автопосты) не сделан: нет даты рождения в стандартном участнике, нужна настройка компании.
6. Аудитория поста «отделы» хранится JSON-массивом id — отдельный App «лента» не зависит от App «структура»; форма публикации пока создаёт только «вся компания».
