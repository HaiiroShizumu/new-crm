### 1. U-1 (часть) — typecheck twenty-front

- Штатная команда `tsgo -p packages/twenty-front/tsconfig.json --noEmit` на этой машине **не
  воспроизводима**: после переустановки бинарь linux-arm64 есть, но процесс получает **SIGKILL**
  (не хватает 8 ГБ на 10 потоков типизации). Заменён на `tsc` (TypeScript 5.9.3) с `--max-old-space-size`.
- Первый прогон: **16 ошибок**, все в перенесённом скине:
  `TS2307 Cannot find module 'twenty-ui/theme-constants'` (13 файлов) и 2× `TS2339 Property 'theme' does not exist`.
  Причина: субпуть `./theme-constants` существовал в **v2.42.6** (база старого билда), в **v2.45.6** его нет —
  `themeCssVariables` выезжает из `twenty-ui/theme`.
- Исправление: 12 файлов — путь `twenty-ui/theme`; `SmbPriorityBadge` — слияние двух импортов
  (`import/no-duplicates`); `SmbRecordBoardColumnTitle` — `ThemeContext` больше не экспортируется →
  `useTheme()` из `twenty-ui/theme` + `type ThemeType as Theme`.
- Итог: `tsc --noEmit` **EXIT=0, 0 ошибок** (прогон и после фикса, и финальный — уже с кодом M-2/M-3).

**Почему первые попытки не шли (найдено и исправлено):**

1. `nx database:init` падал с `/bin/sh: 1: yarn: not found` → `corepack enable --install-directory ~/opt/node24/bin` (EXIT=0 после этого).
2. `run-instance-commands` висел без вывода и без таблиц: в `.env` сервера был
   **`REDIS_URL=redis://localhost:6380`** (порт docker-compose старой сессии), Redis слушает **6379** —
   Nest зависал на переподключении к Redis ещё до старта команды. Исправлено на `6379`.
3. Там же `PG_DATABASE_URL` указывал на порт **5433** → заменён на **5432**.
4. `npx nx start twenty-front` умирал с `exited with code 128` во время депозиции зависимостей vite —
   запущен сам `vite` напрямую (тот же конфиг, `VITE_HOST=0.0.0.0` добавлен в `.env` фронта).
