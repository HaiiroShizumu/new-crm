# 01 — Правила агентов для форка (раздел «Форк» в CLAUDE.md / AGENTS.md)

**Дата:** 2026-10-08. **Статус:** принято.

**Контекст:** форк Twenty обновляется слиянием стабильных тегов upstream каждые 4–6 недель.
Любая правка файлов ядра становится конфликтом при обновлении, поэтому агенты должны
минимизировать правки ядра и фиксировать каждую в `docs/PATCHES.md`.

**Решение:** добавить в `CLAUDE.md` (файл правится один раз — `AGENTS.md` в репозитории
является симлинком на `CLAUDE.md`, git-режим 120000) раздел «Форк» с четырьмя
правилами: новый код только в `packages/smb-*`/`apps/`; правка ядра = запись в реестре,
больше одной строки = плюс ADR; запрет заявлять «тест прошёл» без фактического запуска
(иначе `NOT RUN` + причина); запрет коммитить `locales/*.po` и `locales/generated/*`
вне задач про переводы.

**Последствия:** правка зарегистрирована как `P-001` в `docs/PATCHES.md` (сама подпадает
под собственное правило); CI `check-core-patches`
гарантирует, что раздел не исчезнет молча при следующем обновлении с upstream.
